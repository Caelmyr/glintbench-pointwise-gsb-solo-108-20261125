# Glint Bench 镜球灯位台

用一张镜面球照片核对影棚灯位。推荐用较长焦距沿球心拍摄，让镜面球边缘可见并留在画面中。项目使用正交投影近似，方位为画面向右，俯仰为画面向上，两项的 0° 都朝相机。

1. 打开标明为合成的练习镜球，或导入单帧 PNG、JPEG、TIFF、BMP 或 WebP。
2. 填写原片球心和半径。用点读检查原片像素，或用「选反光点」填入希望核对的像素。
3. 填写目标方向、角度容差和亮区下限，点击「保存并重测」。下方给出穿过该点的亮度剖面，右边显示由该点反射求得的方向和目标夹角。
4. 长条灯等整片亮斑可把「核对方式」切到**整片核对**（点击即保存并重测，重开仍按该方式核对；也可随时切回**单点核对**）：
   - 仍以保存的反光点为种子，只收上下左右四连通、亮度达到亮区下限的像素；标定圆外的像素既不参与也不能用于连通。种子在圆外或亮度低于下限时，会提示重新选点。
   - 用球面反射把整片像素换算成实测方向，给出一个落在实测亮片像素内、兼顾最亮核心与整片角度覆盖的「建议中心」，并显示离该中心最远的亮片角距。
   - 整片方式下，只有亮片的**所有**实测方向都在原目标角度容差内才判合格；建议中心已在容差内但边缘超出时，画布、读数和 PNG 校样都会用红色标出超标边缘并明确判不合格。
5. 从测光卡菜单重新打开已存测量，或下载带标定的 PNG（注明当次是单点还是整片核对及实际结论）、剖面/亮片 CSV 和含原片的 ZIP。需要进一步处理原片时，可把照片直接送入准备工作区。

`docker compose up --build -d --wait` 在本机 19911 端口启动。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后执行 `./start.sh`。运行数据保存在 Compose 命名卷或普通启动的本地数据目录中。
