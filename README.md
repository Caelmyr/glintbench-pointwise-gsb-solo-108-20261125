# Glint Bench 镜球灯位台

用一张镜面球照片核对影棚灯位。推荐用较长焦距沿球心拍摄，让镜面球边缘可见并留在画面中。项目使用正交投影近似，方位为画面向右，俯仰为画面向上，两项的 0° 都朝相机。

1. 打开标明为合成的练习镜球，或导入单帧 PNG、JPEG、TIFF、BMP 或 WebP。
2. 填写原片球心和半径。用点读检查原片像素，或用「选反光点」填入希望核对的像素。
3. 手填的圆心和半径只当作粗标。点「预览精修圈」，程序只在粗半径内外各一成半的环带里找原片实际的球缘，并在原片上画出虚线精修圈。
   - 至少三个象限要分别有沿圆弧的实拍边缘支持；画外的角度、以及只和粗圆碰一下的底座直边都不会算成球缘。
   - 两道轮廓都能贴合时，同时看能证实的圆周覆盖和拟合贴边的误差；覆盖相近且都能在多象限立住，才算「相近轮廓」。
4. 精修圈会用已存反光点和现有目标容差重测。若相近的两道轮廓给出一个合格一个超差，或有一道把已存反光点划到球外，会提示「目前轮廓不足以定准」，手填标定原样保留，也不会出现「采用」按钮。
5. 采用精修圈后，只把精修中心和半径填回现有标定；已存反光点、目标方向、容差、亮区下限都保持不变，保存、点读和校样仍按原流程。
6. 填写目标方向、角度容差和亮区下限，点击「保存并重测」。下方给出穿过该点的亮度剖面，右边显示由该点反射求得的方向和目标夹角。
7. 从测光卡菜单重新打开已存测量，或下载带标定的 PNG、原片读数 CSV 和含原片的 ZIP。ZIP 内的 `measurement.json` 会一并记录本次精修的状态与证据。需要进一步处理原片时，可把照片直接送入准备工作区。

`docker compose up --build -d --wait` 在本机 19911 端口启动。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后执行 `./start.sh`。运行数据保存在 Compose 命名卷或普通启动的本地数据目录中。
